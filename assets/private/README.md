# Private character sheets

This local project expects these four files in this folder:

- `chun_li.png` (losslessly converted from the supplied single-frame GIF)
- `rose.png`
- `fei_long.png`
- `cammy.png`

Character-selection portraits are stored as normalized PNG inputs under `portraits/` and displayed inside the same fixed-size portrait area by the game.

They are intentionally excluded from source-control and any shareable package. Keep your personal reference files local.
